# repo management

- 先区分本轮改动、用户已有改动和生成物。
- 新增、迁移或沉淀长期文档时，同步更新主入口或目录索引；若项目有 `docs/README.md`，`docs/**/*.md` 必须出现在该索引。
- 删除或整理文档时，直接移除失效内容，同步修正正文、索引和引用，不用“已删除 xxx”等说明占位。删除时间、原因和内容通过版本控制与提交说明保留，不另建删除历史文件，也不在其他文档重复记录。
- 清理旧方案时同时删除入口、桥接、兼容层和测试。
- 版本控制收尾要能被 `git log` 或 jj graph 验证。
