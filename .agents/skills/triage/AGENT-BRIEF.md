# Agent Brief

`ready-for-agent` 的 brief 必须让新会话无需重新阅读整段讨论即可实现。

```markdown
## Problem

用户可观察的问题、受影响对象和重要性。

## Verified Evidence

- 复现命令与结果。
- 相关代码、日志、截图或请求路径。

## Expected Behaviour

成功行为与关键失败路径。

## Scope

- In：本票需要改变的行为。
- Out：明确不做的内容。

## Implementation Constraints

相关 glossary、ADR、模块边界、兼容和迁移约束。

## Acceptance

- 面向行为的可验证条件。

## Verification

- 最小测试与完整验证命令。
```

引用已有 spec、ADR、issue 或文档，不复制其全文；不把未经核实的推测写成事实。
