# Restate Goal

用自己的话重述用户当前的目标，以及用户试图解决的问题。这个 skill 只产出共享理解，不开始实施方案。

## 依据范围

- 读取当前对话，以及用户明确引用的文件、链接或其他材料。
- 需要材料中的事实时，只读必要部分；不要做宽泛工作区检索或联网扩展。
- 区分用户明确说出的内容与根据上下文作出的推断；没有依据的内容不要补全。

## 输出

用中文 Markdown 输出两部分：

## 你想达成的目标

说明用户希望最终得到的结果、改变或能力；优先写可观察的结果和边界。

## 你试图解决的问题

说明促使用户提出请求的障碍、缺口、风险或约束，解释它与目标的关系。

对推断、信息不足或存在歧义的句子，在句首标注 `【推断】`、`【信息不足】` 或 `【不确定】`。不要把推荐方案、实现细节或尚未确认的选择写成用户目标。

不要逐字复述用户原话，不要提出后续问题，不要给出实现计划；如果证据不足，明确保留未知项。
