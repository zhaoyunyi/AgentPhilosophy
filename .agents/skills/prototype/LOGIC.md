# 逻辑原型

用于状态机、规则、调度、数据形状和算法问题。

- 优先构建一个无需安装、构建或启动服务的自包含 HTML 文件，使用原生 HTML/CSS/JavaScript。
- 把可复用的纯逻辑放在独立 JavaScript 模块或清晰函数区域，HTML 只承担可视化和交互外壳。
- 页面必须使用项目领域语言展示状态面板、输入、状态转换和输出，不能只给开发者看原始 JSON。
- 始终提供自由操作按钮，让用户可以探索任意状态变化；同时用 tab 或同等结构提供代表性 guided walkthroughs，列出每个场景的操作顺序和预期观察。
- 只模拟回答问题所需的依赖，不复制整套生产架构。
- 输出应同时便于人观察和自动化比较，必要时提供稳定的状态文本或导出按钮。
- 完成标准是设计问题得到回答，不是代码覆盖率或可发布质量。
