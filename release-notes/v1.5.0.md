# AgentPhilosophy v1.5.0 发布说明

状态：2026-11-17 发布候选。本地验证已通过；固定提交 CI、远端 tag / Release 和制品回读完成后回填正式发布回执。

## 变更摘要

- 新增中文 `test-suite-pruning` skill，将用户附录中的风险驱动测试精简流程、决策案例、图标及调用配置纳入中央内容源和包内镜像，完整分发到仓库级与 Codex 项目级技能目录。
- 通用测试规范新增测试套件治理：保护当前行为合同，按输入、断言、系统边界和失败模式判断重复，区分一次性删除验收与持续有效的安全、兼容、迁移负向合同，禁止为变绿而跳过或削弱断言。
- 四类默认 preset 包含新 skill；`AGENTS.md` 和测试规范根据已选模块及实际目录生成入口。补齐下游接入、调用与冲突处理说明。
- 相对上一正式版 `v1.4.0`，本次增加向后兼容能力，因此 CLI 和内容源统一提升至 `1.5.0`。CLI 命令行为和运行时依赖保持兼容。

## 模块版本变化

| 模块 | 版本 | 变化 |
| --- | --- | --- |
| `skill-test-suite-pruning` | 新增 `1.0.0` | 测试精简、功能退役与回归保护流程 |
| `spec-test-general` | `1.2.0` → `1.3.0` | 测试套件治理规范与技能导航 |

## 兼容性与迁移

- 无模块移除、输出改名或 state schema 变更。原有项目模块选择、自定义目录、变量与 custom 内容保留。
- 新项目四类默认 preset 均获得测试规范与完整 skill。旧项目已有 `spec-test-general` 会随正常同步更新规范；首次采用新 skill 需在现有 `modules` 中追加 `skill-test-suite-pruning`，以后随正常同步持续更新。
- 新 skill 可独立安装；只选择测试规范时不会生成指向未安装 skill 的文件入口。显式旧 `.codex/skills` 与自定义 `.claude/skills` 输出继续支持。
- 同名非托管技能与手改托管文件沿用冲突保护，不自动覆盖。安装或同步 skill 不执行测试删除、不创建调度、不修改其他项目。
- 完整步骤见[测试套件治理与精简](../docs/cli/test-suite-pruning.md)和[独立项目升级指南](../docs/cli/upgrade.md)。本次发布不批量更新真实依赖仓库。
- 正式 tag 中 README 保留上一已发布稳定入口；发布后的独立主线提交再更新为 `v1.5.0`。

## 回滚入口

- 项目内容升级后，使用 `rollback PROJECT --id ID --dry-run` 预览，再用 `--apply` 恢复本次升级前的文件与 state；保留升级回退 ID，不以旧内容源强制覆盖手改文件。
- CLI 可重新安装上一正式版 `v1.4.0`；项目内容回退不自动降低 CLI 版本。
- 显式追加新 skill 后的普通同步属于单独配置变更，不能假定旧升级快照包含它；按该次变更记录恢复配置与托管输出，并保留用户自有文件。
