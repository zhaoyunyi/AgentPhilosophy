## 兼容性与迁移

本版是非兼容内容更新，不保留旧词汇文件名与旧 skill 命令的兼容入口。

- 领域词汇使用 `GLOSSARY.md`，多上下文项目以 `GLOSSARY-MAP.md` 索引各上下文词汇；已有领域资料需要在对应项目中迁移内容并修正引用，不能同时保留两份词汇真值。
- spec 与 ticket 工作流使用 `to-spec` 和 `to-tickets`，Agent 文档编写使用 `writing-for-agents`。整份 spec 编排使用 `implement-spec`；单票实现继续使用 `implement`。
- `implement-spec` 与 `retro` 保持显式调用，`pr` 可在编写 PR 正文时由模型发现。已有 `matt_implicit_skills` 的三个配置值保持原合同。
- 对已有项目先检查配置和托管漂移，依次运行中央/目标 `validate`、`push --dry-run`、`push --apply`，确认新版输出完整后再执行 `push --prune-managed`。
- prune 只清理 state 登记且哈希未变的失活输出；手改文件报告冲突并保留。项目自有领域文档不会被同步器自动改名或覆盖。
- Superpowers、Ponytail 继续显式可选；本版更新中央内容，不安装全局插件或改变本机 Portless 运行实例。
