## 兼容性与迁移

- 新项目使用当前默认 preset 时会获得本版本的默认模块集合。
- 旧项目的 `.agentphilosophy.yaml` 模块列表是显式冻结的；升级 CLI 不会自动追加新模块，先按发布摘要审查后再修改配置。
- 本版本包含模块版本变化；依赖项目同步前先运行 `status` 与 `push --dry-run` 审查影响。
- 安装 AgentPhilosophy 会同时安装 code-review-graph 的基础依赖，安装体积和依赖数量会增加；embeddings、云端 API 和额外模型依赖仍未默认启用。
- AgentPhilosophy 同步只生成项目级 skill，不会自动修改用户级 Codex 配置。需要 MCP 时先运行 `code-review-graph install --platform codex --repo . --dry-run`，确认后再安装并重启 Codex。
