# AgentPhilosophy v2.2.0 发布说明

## 变更摘要

- 将前端布局、配色、字体、间距、图标、桌面菜单与浏览器验收规则整合到一份可复用的 `UISpec.md`。功能文档可直接引用；目标项目的 `AGENTS.md` 会指向实际规范目录。
- 保留现有页面状态与中英文文案要求，明确可省略的装饰性说明，以及必须保留的错误原因、权限提示和下一步操作。
- AgentPhilosophy CLI 与默认内容源均更新到 `2.2.0`。

## 本次 diff 重点

- CLI/脚本：`pyproject.toml`、`src/agentphilosophy/__init__.py`、`uv.lock`。
- 中央内容源：`catalog.yaml`、`modules/spec-ui/module.yaml`、`modules/spec-ui/templates/UISpec.md.j2`、`modules/spec-ui/templates/ui-rules.md.j2`、`src/agentphilosophy/default_source/catalog.yaml`、`src/agentphilosophy/default_source/modules/spec-ui/module.yaml` 等 2 个文件。
- 文档：`README.md`、`docs/README.md`。

## 模块版本变化

- `spec-ui`：`1.1.0` -> `1.2.0`，UI 和设计系统规范。

## 兼容性与迁移

- 前端、全栈和移动 SDK 预设仍默认启用 `spec-ui`；既有项目的模块选择不变。启用该模块的项目同步后可获得新版规范与入口。
- 保持原有文件路径与分层生成方式。已有项目约定继续优先；新视觉参数作为缺少项目专属约定时的基准。
- 对已接入项目按[独立项目升级指南](../docs/cli/upgrade.md)先预览差异，再应用。

## 最近提交参考

- 规范：整合可复用的前端界面设计规则
- 文档：回填 2.1.0 稳定安装入口

## 依赖项目影响

- `agentphilosophy_version` 会写入依赖项目的同步状态。
- `source_content_version` 用于提示依赖项目是否需要同步新一轮中央内容。
- 默认内容源有文件变化，依赖项目同步前先运行 `push --dry-run` 审查托管输出计划。
- 依赖项目可能看到 `module version stale`，优先审查 `spec-ui` 对应输出。
- 外部技能继续沿用已锁定版本。Matt Pocock 的领域建模词汇表模板出现上游变化，留待独立审查。

## 回滚入口

- CLI 或中央内容需要回退时，恢复到 `v2.1.0`，并保持 CLI、内容源与目标项目 state 的版本关系可解释。
- 已应用事务升级的项目可用 `agentphilosophy-sync rollback . --id <升级ID> --dry-run` 预览，再加 `--apply` 恢复该次升级的快照。
- 回退后先运行 `validate`、目标项目 `status` 和 `push --dry-run`；不要直接用旧内容源覆盖已经由新版本写入且被人工修改的托管文件。
