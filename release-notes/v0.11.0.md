# AgentPhilosophy 0.11.0

状态：本地候选，尚未创建 tag 或 GitHub Release。

## 变更摘要

- 封闭模块模板、manifest、复制资源与符号链接的越界读取，模板使用沙箱渲染；校验失败不产生正式输出或冲突候选。
- 共用内容源清单，排除系统元数据和缓存；新增镜像检查/刷新入口，打包仅包含清单资源。
- 发布从不可变提交构建，校验 CLI/content 版本、制品摘要与回执，并独立回读远端 tag 和下载制品。
- 新项目使用 `.agents/skills`；旧配置保留兼容。澄清 Claude 目标的配置方法，修正跨目录 Python 环境选择。
- 收敛应急授权、文案受众、目录与上下文读取、review 基线和 Superpowers 显式调用规则。
- CLI 文档按任务拆分，完整 `llm-usage` 输出保留；上游检查区分内容、引用和正式发布，并汇总错误。
- Portless 参考 0.15.6；reverse 筛选 v1.0.1 精确快照；Superpowers 中央说明参考 6.3.0。详情见[本轮筛选记录](../docs/plans/2026-09-06-audit-remediation.md)。

## 兼容性与迁移

- 既有显式 `.codex/skills` 配置和 state 已登记的历史默认目录不会自动改名。迁移先检查旧文件、新目录冲突与完整资源，应用后再按状态清理旧托管输出。
- 内置模块仍输出两个配置目标；Claude 用户可使用 `repo_skills: .claude/skills`。保留的 `claude_project` 字段仅供显式引用它的自定义模块使用。
- 目录符号链接、模块外模板/manifest/复制资源、忽略的缓存资源及不安全模板表达式现在会被明确拒绝；将真实资源放回模块内再验证。
- `check-skill-upstreams.py` 默认进行内容与正式发布检查；旧的纯引用比较可使用 `--refs-only`，不再把它等同于能力更新。
- reverse 正式标签与 VERSION 不一致：v1.0.1 快照中的 VERSION 写为 1.1.0。封装以 commit `9c28c6ca1062a1a076e28baf40f241dbb4cf5dc2` 识别来源，排除预授权、Force 绕过和自动副作用规则。
- 本轮不改变默认图谱依赖或自动安装工具；Superpowers 说明更新不创建全局发现入口。
