# AgentPhilosophy 1.2.0

状态：候选改动，尚未发布；本次交付为 PR。稳定安装入口保持 `v1.1.0`。

## 变更摘要

- 新增 `skill-loop-check` 1.0.0：为仓库生成每日/事件巡检计划，在已有授权范围内修复、复查并提交 PR，支持未解决项跟踪、并发与重复 PR 去重。
- 四类默认 preset 提供双目录技能与检查候选、计划指引；本仓新增自有巡检计划与文档入口，未启动定时任务。
- 退役覆盖代码、文档、专属测试与残留引用，不留占位；统一文档只记对象/原路径和完整删除 Git 提交 SHA，处理提交自引用与 squash/rebase 后追溯。
- CLI/内容源候选版本为 `1.2.0`；`doc-templates` 和 `skill-repo-management` 升至 `1.3.0`，统一退役规则。依赖及上游锁定 revision 保持不变，本轮不包含外部 skill 升级。

## 兼容性与迁移

- CLI 参数与 state schema 保持兼容；新增巡检能力按 MINOR 提升。新项目默认获得技能，已有项目的显式模块清单不会自动新增模块，需要追加 `skill-loop-check` 并按 validate → dry-run → apply → status 同步。
- 自有巡检计划不属于托管输出，同步不会覆盖它。更新 `doc-templates`/`repo-management` 后采用统一退役文档规则；不追补编造历史删除条目。
- 日检/事件触发是技能执行策略；真实调度、hook 和宿主发现另行验证。没有自动合并、发布、生产操作或跨仓写入。
- README 固定安装链接仍指向已发布 `v1.1.0`；发布回执闭环后才更新稳定入口。

## 验证结果

- 新增 BDD 先验证缺少模块的失败，再验证四类 preset 安装、双目录资源一致、自有计划保护与同名技能冲突保护通过，共 6 个场景。
- `uv run --locked ruff check .` 通过；完整测试 `239 passed`（167.67 秒）。首轮离线打包用例因本机缺少 wheel 缓存失败，正常构建补齐后按原命令全量重跑通过，未放宽测试。
- 中央/本仓 validate、镜像检查、同步 dry-run → apply → status 和技能结构校验通过。
- wheel / sdist 构建通过，wheel 中 Loop-Check 的 5 个中央模块资源与当前源逐一一致；中立目录安装 smoke 通过，回读 CLI / 内容源均为 `1.2.0`。
- Standards / Spec 双轴审查通过；静态规则审查不能代替实际定时巡检、退役执行或宿主发现验收。
