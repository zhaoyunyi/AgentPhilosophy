# AgentPhilosophy v0.10.0 发布说明

## 变更摘要

- 将 AgentPhilosophy CLI 与中央内容源提升到 `0.10.0`。
- 将 `skill-mattpocock-engineering` 从 `1.4.0` 升级到 `1.5.0`，新增项目级 `matt_implicit_skills` 配置。
- 当前只允许项目按需把 `to-spec`、`to-tickets`、`implement` 加入隐式调用；默认值为空列表，因此现有项目不会被全局自动开启。
- 将 `spec-bdd` 从 `1.0.0` 升级到 `1.1.0`，把 `BDDSpec.md` 改为 layered 输出，允许项目通过 `.agents/custom/spec/BDDSpec.custom.md` 保留本地行为场景。

## Skill 调用策略

项目可在 `.agentphilosophy.yaml` 中配置：

```yaml
vars:
  matt_implicit_skills:
    - to-spec
    - to-tickets
    - implement
```

- 未配置或配置为空列表时，上述三个 skill 继续生成 `allow_implicit_invocation: false`。
- 配置后，repo `skills/` 与 Codex `.codex/skills/` 的 `agents/openai.yaml` 同时生成 `allow_implicit_invocation: true`。
- `grill-*`、`triage`、`wayfinder`、`handoff`、项目设置入口以及 `to-prd`、`to-issues`、`writing-great-skills` 兼容入口不受影响。

## 兼容性与迁移

- 本版本为向后兼容功能更新，不删除 skill，也不改变默认调用策略。
- 旧项目模块列表仍保持显式冻结；只有已经启用 `skill-mattpocock-engineering` 或 `spec-bdd` 的项目会看到对应模块版本更新。
- 依赖项目需要隐式调用时必须显式增加 `vars.matt_implicit_skills`，随后依次执行目标 `validate`、`push --dry-run`、`push --apply` 和 `status --project`。
- 已经维护 BDD 项目扩展的仓库，应将长期自定义内容保留在 `.agents/custom/spec/BDDSpec.custom.md`，不要直接编辑托管的 `spec/BDDSpec.md`。

## 回滚入口

- 上一正式版本为 `v0.9.0`。
- 回滚 CLI 或中央内容源时使用 `v0.9.0`，并先在依赖项目运行 `status` 与 `push --dry-run`。
- 不要用旧内容源强制覆盖已被人工修改的托管文件；需要撤销项目隐式调用时，优先删除 `vars.matt_implicit_skills` 后按标准同步流程应用。
