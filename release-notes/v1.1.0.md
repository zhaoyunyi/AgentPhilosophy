# AgentPhilosophy 1.1.0

状态：已正式发布。远端 CI、tag、GitHub Release、制品摘要和固定 tag 安装均已独立回读。

## 变更摘要

- 新增 `restate-goal` 技能：用自己的话重述用户目标与待解决的问题，区分明确事实、推断与未知项；只产出共享理解，不主动追问或开始实施。
- `orchestrator` preset 默认包含 `skill-restate-goal`，同时分发仓库级与 Codex 项目级技能正文和调用 metadata。
- 将主线上新增的可选 `ui-ux-loop` 纳入稳定发布，提供有证据的界面检查、修复、复查与停止条件；支持 `review-only` 和 `loop`，缺少界面输入时保留未验证状态。
- CLI、默认内容源、包内镜像、锁文件和本仓 state 统一为 `1.1.0`。

## 兼容性与迁移

- 本版为向后兼容的内容新增，CLI 参数和 state schema 保持原合同。
- 新建 `orchestrator` 项目会获得 `restate-goal`；其他 preset 不自动追加该模块。已有项目的模块列表显式冻结，升级 CLI 后按需要增加 `skill-restate-goal`。
- `ui-ux-loop` 是面向 `frontend` / `fullstack` 的可选模块，需在项目配置中明确增加 `skill-ui-ux-loop`，不会因升级 CLI 自动启用。
- 依赖项目先运行中央和目标 `validate`、`status`、`push --dry-run`，审查托管输出后再 `push --apply`。本次发布不批量修改依赖项目。
- 技能 metadata 允许隐式发现；具体宿主是否选择调用仍需在目标宿主验证，文件同步不等于宿主行为验收。
