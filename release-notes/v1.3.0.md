# AgentPhilosophy v1.3.0

状态：已正式发布。固定提交 CI、远端 tag / Release、制品下载回读与正式版本间升级/回退验收均通过。

## 变更摘要

- 新增 `check-update`，从正式稳定 Release 核对 tag、源码提交、发布回执、wheel 摘要和内容指纹。
- 新增单项目 `upgrade` 预览/应用与 `rollback`，保留模块选择和定制，提供文件差异、兼容检查、快照、失败恢复及重复执行保护。
- 同步 skill 增加一句话升级协议；README 区分外部使用者、手动升级与中央维护者，公开安装入口优先 HTTPS。
- CLI / 内容源为 `1.3.0`；`skill-agentphilosophy-sync` 为 `1.2.0`。其余外部技能与依赖不因本次升级功能自动更新。

## 兼容性与迁移

- 原 `init/migrate/adopt/push/status` 接口保留，`status` 继续只比较本地源。
- 旧 CLI 先安装新版正式稳定 Release 才能使用新命令。新目标固定源码提交，升级不自动扩展 modules。
- 已有 state schema 1 保持，升级后增加 `release_target` 身份；回退恢复原 state。项目快照在 `.agents/upgrades/`，自带忽略规则。
- CLI、内容源或已选模块跨主版本、模块选择变化及输出退役需用户评估后显式允许。未知版本、降级和手改冲突不能跳过。
- 文件验证与宿主发现、项目业务验证分别报告；macOS/Linux 为本仓 CI 平台，Windows 锁路径仍需实际环境验收。
