状态：候选修复，尚未发布。稳定安装入口仍为 `v1.1.0`；本版包含尚未正式发布的 `1.2.0` 巡检能力及以下修复。

## 变更摘要

- 修正 JSON 用户配置向导的推荐目录，使其与新项目实际生成的 `skills/`、`.agents/skills/` 一致。
- 保留原选项 ID，但明确仅仓库输出和三个独立目录需要自定义模块；内置模块仍为两路输出，省略 `codex_project` 不会关闭第二路，设置 `claude_project` 也不会新增第三路。
- Loop-Check 计划路径按项目 `paths.custom_dir` 渲染，复用已有自定义目录和计划，不另建默认计划。
- CLI / 内容源候选版本为 `1.2.1`，`skill-loop-check` 为 `1.0.1`；其他依赖和模块版本保持不变。

## 兼容性与迁移

- CLI 参数、结构化向导的格式版本/选项 ID、默认输出及旧 `.codex/skills` 兼容行为保持不变。
- 已有项目按 validate → dry-run → apply → status 更新技能；项目自有计划仍不属于托管输出，不迁移或覆盖用户内容。
- 省略 `paths.custom_dir` 时继续使用 `.agents/custom`。只用 Claude 与 Codex 的项目可将 `repo_skills` 指向 `.claude/skills`，无需第三路内置输出。
