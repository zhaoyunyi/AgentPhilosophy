# 仓库计划格式

首次建立或修改计划时读取。复用已有格式；没有时使用 SKILL.md 中已按本项目 `paths.custom_dir` 渲染的计划路径，并接入项目入口。该配置缺省值为 `.agents/custom`，已有自定义目录时不另建默认目录。下列字段是填写指引，不原样生成带占位符的文件。

## 必需信息

- **范围与授权**：仓库、允许修改的路径/动作、只读或修复并提交 PR、授权来源、排除项。明确仓库修复和运行环境/生产数据的边界；计划不授予超出用户要求的权限。
- **触发**：哪些项每日、哪些事件触发、全量复核周期；有真实调度时记录执行器、时区、调度标识，否则标记未启用。事件触发是 agent 的选择规则，只有实际配置 hook/CI 才称为已自动接线。
- **执行约束**：本轮时间/资源预算、工作区隔离、并发去重、验证命令、唯一退役文档路径、当前结果保存位置。优先沿用仓库现有机制。
- **检查项**：稳定 ID、目标、适用范围、证据来源、运行命令或读取步骤、通过标准、可自动修复范围和复查方法。首次不强制凑齐所有候选。
- 对涉及 PR、部署、业务或清理的仓库，优先显式启用证据层级与工作区/恢复价值检查；没有当前证据的层级保持未验证，不能把本地通过升级成部署或业务完成。
- **结果**：每项最后完整检查的 revision/时间、通过/问题/未验证/阻塞/不适用、证据、未解决项与已有 PR。结果与计划可分文件，但不复制整套检查定义；证据不含凭据或完整敏感日志。

## 可直接解释给执行器的调用方式

按该仓库实际文件和授权填写自然语言任务：读取巡检计划与未解决项，执行到期或事件相关检查；在既有范围内自动修复并验证，创建或更新对应 PR；保留 WIP，不合并或部署；无可行动变化保持安静；失败或缺证据明确报告。

每日执行由调度器唤醒，技能自身不常驻等待。用户只要求创建技能/清单时，不批量修改其他仓库或注册所有项目的定时任务。

## 行为验收场景

- **user 首次建立清单**：Given 仓库已有规则、测试命令和迁移历史；When 建立巡检；Then 清单使用这些真实入口并可从主入口到达，不把候选全部强制启用，不谎称调度已运行。
- **user 自动修复并提交 PR**：Given 用户已授权仓库维护；When 巡检发现可复现的漂移；Then 直接修改权威源、生成、验证和提交 PR，不再等逐项审批。
- **user 保留退役追溯**：Given 替代路径验收且消费者迁移完成；When 删除旧实现、专属测试和文档；Then 原位置无占位，引用修正，统一文档的删除 SHA 可查到原内容，且不尝试在提交内写自身 SHA。
- **user 保护现有行为**：Given 旧代码无本仓引用但仓库外消费者未知，或旧测试仍验证公共合同；When 巡检；Then 相关删除保持阻塞，其他可修复项继续，不自动删除历史数据库迁移或有效测试。
- **user 重复巡检**：Given 同根因开放 PR 或已有执行；When 日检再次触发；Then 更新或复用已有任务，不复制 PR、不重叠写同一工作区；无变化不刷通知。
- **user 看见真实验证状态**：Given 命令失败/观察不完整/只有本地绿测；When 汇报；Then 不报告全仓通过、已部署或业务完成，不推进完整检查基线。
