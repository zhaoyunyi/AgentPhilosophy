# 至少设计两次

技术 brief 同时使用本 skill 的架构词汇和项目 `GLOSSARY.md` 的领域词汇，让候选接口命名一致。

当接口选择不可逆或存在真实权衡时，分别提出至少两种结构明显不同的方案。

逐项比较：

- Interface 大小与调用者认知负担。
- 隐藏了多少复杂度。
- seam 是否落在真实变化点。
- adapter 是否来自真实替代物。
- 失败模式、迁移成本和测试面。
- 对领域边界与现有 ADR 的影响。

如果环境和任务允许，可让独立 agent 各自设计，再由当前会话统一比较；写入范围必须互不冲突。最终记录为什么选择某方案，而不只记录方案本身。
