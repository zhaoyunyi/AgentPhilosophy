# 会话阶段边界

阶段是一次连续工作的自然片段，例如需求澄清、实现、review 或 QA。只有当前阶段已经结束时，才选择如何承接下一阶段；阶段中途优先继续，或把独立旁支交给子 agent。

按顺序判断，第一个“是”就是选择：

1. **能继续当前会话吗？** 下一阶段需要当前讨论作为一手来源，且上下文仍足够清晰时直接继续。
2. **当前上下文与下一阶段完全无关吗？** 是则清空上下文，旧会话仍可恢复。
3. **内容需要跨工具、目录、仓库或人员移动吗？** 是则用 `/handoff` 生成可携带的 Markdown。
4. **任务边界清楚并可无人值守完成吗？** 是则交给子 agent，主会话保留原始上下文。
5. **其余情况**：在阶段边界 compact，并明确下一阶段要保留的决定、证据和未决项。

`/handoff` 的价值是可携带性，不是一般性的上下文压缩。compact 是同一工具、同一目录继续工作的默认兜底，但不应在阶段中途使用。
