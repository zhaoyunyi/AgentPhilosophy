# repo management

- 先区分本轮改动、用户已有改动和生成物。
- 新增、迁移或沉淀长期文档时，同步更新主入口或目录索引；若项目有 `docs/README.md`，`docs/**/*.md` 必须出现在该索引。
- 删除或退役文档、代码、测试等内容时，直接移除失效内容，同步修正入口、索引和引用，不用“已删除 xxx”、空壳或跳过测试占位。统一退役文档只记录退役对象/原路径与可追溯的完整删除 Git 提交 SHA；删除内容和原因通过版本控制查看，不复制旧内容或另建逐次归档。
- 确认替代路径与消费者迁移后清理旧入口、桥接、兼容层和专属测试；仍验证现有合同的测试随实现迁移，未知引用阻塞对应删除。
- 版本控制收尾要能被 `git log` 或 jj graph 验证。
